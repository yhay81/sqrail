  -t trials=trials.parquet \
  --memory 512MB --threads 2 \
  'SELECT phase, count(*) AS n
   FROM trials
   GROUP BY phase
   ORDER BY phase'

Thirty-second contract

No prompt layer.
No daemon.
Just the rail.

The model supplies SQL. sqrail supplies canonical file binding, streamed execution, atomic output, bounded resources, and strict JSON diagnostics. One executable; no language runtime.

Complete interface

Small enough to learn once.

The full agent-facing contract fits in one terminal screen.

sqrail schema FILE...
sqrail check [-t NAME=PATH]... [--timeout 30s] SQL
sqrail run [-t NAME=PATH]... [-o FILE] [--memory 1GB]
           [--threads 2] [--spill DIR] SQL

# Learn everything an agent needs:
sqrail --agent-help

Constrained by default

Give SQL only the files it needs.

Exact inputs are allowlisted. Extension loading and arbitrary external access are disabled. Output is private until an atomic, no-overwrite commit succeeds.

  • One read-only SELECT, VALUES, or WITH query
  • Strict JSONL rows and JSON diagnostics
  • Memory, thread, timeout, and private spill controls
